# Simplify

A nature-themed web app with everyday utilities in one place. Built to practice component structure, routing and clean, responsive UI.

## Tools

**CPF generator:** generates valid Brazilian CPF numbers for testing.

**Currency converter:** converts between currencies using live exchange rates.

## Stack

React 18, TypeScript, React Router, Axios, Create React App. Deployed to GitHub Pages with GitHub Actions.

## Getting started

**Requirements:** Node 18+.

```bash
git clone https://github.com/Alan-VSouza/simplify.git
cd simplify
npm install --legacy-peer-deps
npm start
```

The app runs at http://localhost:3000. Create a production build with `npm run build`.

## Project structure

`src/pages` holds the screens, `src/components` the reusable UI (layout, buttons, cards, inputs), `src/hooks` custom hooks and `src/styles` the CSS.
